TwinCity UI

도시와 시설에서 발생하는 이벤트를 하나의 운영 맥락으로 연결합니다. 공개 데모는 합성 데이터로 상황 인지, 담당자 배정, 대응 기록, 보고서 생성 흐름을 검토할 수 있게 구성했습니다.

라이브 콘솔 열기 소스 저장소

운영 판단에 필요한 맥락을 한곳에

TwinCity UI는 단순 지도가 아니라 사건의 현재 상태와 다음 행동을 함께 보는 운영 화면을 지향합니다. 공개 버전의 모든 예시는 실제 고객이나 생산 시설 데이터가 아닌 합성 시나리오입니다.

이벤트 통합

시설, 구역, 장비에 흩어진 이벤트를 시간과 위치 기준으로 묶어 중복 경보보다 영향 범위를 먼저 파악합니다.

대응 배정

우선순위, 담당 영역, 준비 상태를 함께 표시해 누가 무엇을 확인해야 하는지 운영 인계의 기준을 남깁니다.

보고서 추적

상황 요약, 조치 이력, 남은 위험을 같은 사건 기록에 연결해 종료 후 검토와 재발 방지에 활용합니다.

재생과 비교

합성 이벤트 타임라인을 다시 재생하며 대응 순서와 판단 근거가 어떤 결과 차이를 만드는지 검토합니다.

공간 맥락

지도와 평면도는 시각 장식이 아니라 인접 구역, 접근 경로, 영향 확산을 확인하는 운영 근거로 사용합니다.

검증 가능한 출력

요약과 보고서에는 원본 이벤트와 시간 정보를 연결해 사람이 다시 확인할 수 있는 흔적을 유지합니다.

사건이 보고서가 되기까지

운영 흐름은 화려한 자동화보다 명확한 상태 전환에 초점을 둡니다. 각 단계에서 사람이 결과를 검토하고 다음 조치를 승인할 수 있습니다.

1. 감지합성 이벤트를 구역과 자산에 연결합니다.
2. 평가영향, 긴급도, 확인되지 않은 가정을 구분합니다.
3. 대응담당자, 조치, 인계 상태를 기록합니다.
4. 검토결과와 근거를 보고서로 묶어 재검토합니다.

공개 데모의 데이터 경계

이 공개 화면은 제품 구조와 상호작용을 검토하기 위한 합성 데이터 데모입니다. 실제 개인 정보, 고객 시설 정보, 비밀 키, 생산 장애 기록을 입력해서는 안 됩니다.

라이브 콘솔의 판단 결과는 운영자를 보조하는 참고 정보이며, 안전·보안·규제 의사결정을 대신하지 않습니다. 실제 환경 연결은 데이터 보존, 접근 통제, 책임 범위를 별도 합의한 뒤 진행해야 합니다.
